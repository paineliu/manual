# 常见问题排查

> **文档状态：评审初稿，内容待核验。** “待确认”项需核实后才能作为正式用户说明。

[用户指南首页](index.md) · [English](../en/troubleshooting.md)

先找到你遇到的现象，按建议完成基础检查。如果仍未解决，保留原始数据和错误提示，查看[联系支持](support.md)。

| 现象 | 先检查什么 | 下一步 |
| --- | --- | --- |
| 无法开机 | 供电是否连接正确，是否使用指定配件，设备是否有损坏 | 按交付说明检查；仍无响应则联系支持 |
| 无法开始录制 | 是否存在电量、存储或设备异常提示 | 记录提示；按已确认的操作说明处理 |
| 画面被遮挡或模糊 | 镜头是否清洁，佩戴方向是否正确，头发或衣物是否遮挡 | 调整后重新做短测试 |
| 找不到本次数据 | 是否已停止并保存，是否查看了正确设备和存储位置 | 保留现有文件，不要通过格式化尝试恢复 |
| 复制或检查报缺文件 | 是否复制了完整会话，源介质是否可读 | 对比源目录与副本；避免自行补造元信息 |
| 时间或日期异常 | 检查报告是否提示设备时间错误 | 保留数据并记录异常，确认影响后再使用 |
| Collecta 提示设备未登记或未绑定 | SN、设备状态和采集员绑定是否正确 | 请有权限的人员登记或修正绑定 |
| Collecta 选不到任务 | 任务是否已发布、账号是否有权限 | 联系项目管理员确认 |
| 上传中断 | 网络、源文件访问和电脑休眠状态 | 保持源文件可读，按工具提示处理 |
| 上传后处理失败或质检不通过 | 会话详情中的具体失败项 | 按报告处理；涉及原始数据问题时联系支持或重采 |

> **待确认：** 增补 Ego 4 正式错误码、指示灯对应故障和型号专属恢复流程。尚未确认的复位、刷机、格式化操作不在本页提供。

## 联系支持前

准备设备 SN、版本、问题发生时间、复现步骤，以及错误截图或检查报告。先查看日志是否包含账号信息或敏感内容，仅通过指定支持渠道提供排查所需部分。
