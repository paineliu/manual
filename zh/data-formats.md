# 文件与数据说明

> **文档状态：评审初稿，内容待核验。** “待确认”项需核实后才能作为正式用户说明。

[用户指南首页](index.md) · [English](../en/data-formats.md)

一次录制产生一组相关文件，称为一个“会话”。保存、复制和上传时，应以完整会话为单位。

## 先了解文件用途

以下是项目数据规范中的文件类别，用于帮助理解数据；最终文件名、是否交付及读取方式以已确认的设备版本为准。

| 类别 | 用途 | 使用建议 |
| --- | --- | --- |
| 各路视频 | 保存相机画面 | 检查各路是否对应同一次任务 |
| 视频时间戳 | 对应每帧的采集时间 | 做同步或算法处理时与视频一起使用 |
| IMU 数据 | 记录设备运动测量 | 与对应时间信息一起读取 |
| 会话元信息 | 标识设备、会话及采集配置 | 保留原文件，不手动修改身份信息 |
| 标定数据 | 描述相机参数及传感器关系 | 使用与设备及版本匹配的标定 |
| 文件清单 | 描述会话文件及完整性信息 | 用提供的工具校验，不自行改写 |
| 音频（若交付） | 保存声音及相关时间信息 | 是否存在以交付配置为准 |

## 使用数据时注意什么

- 不同时间戳可能属于不同时间基准，不能仅凭数值相近就认定已经同步。
- 不要把视频容器播放时间直接当作已经确认的硬件采集时间。
- 遇到受保护或无法直接读取的配套文件，使用项目指定工具处理，保留原始文件。
- 会话名称中的日期不一定足以证明设备时钟正确，时间异常应结合检查报告确认。
