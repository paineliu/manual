# 日常采集

> **文档状态：评审初稿，内容待核验。** “待确认”项需核实后才能作为正式用户说明。

[用户指南首页](index.md) · [English](../en/recording.md)

目标：每次采集前完成必要检查，结束后留下完整、可检查的数据。

## 采集前检查

- [ ] 镜头清洁，各路视野未被遮挡。
- [ ] 佩戴稳固、舒适，不影响视线和活动。
- [ ] 电量和可用存储空间足够完成本次任务。
- [ ] 任务内容、场地和需要记录的操作已经明确。
- [ ] 已按任务要求确认设备时间；存在时间异常时先处理。
- [ ] 首次使用、修改设置或更换配件后，已完成测试录制。

## 采集过程

1. 开始录制，并确认设备已进入录制状态。
2. 按任务要求完成操作，尽量让关键动作持续处于视野内。
3. 留意设备异常提示。发现录制异常时，在安全的情况下结束当前任务并检查。
4. 完成任务后停止录制，等待保存完成。

> **待确认：** 录制操作、状态标志，以及存储不足、电量不足或异常中断时的实际提示与恢复步骤。见[认识设备](device-overview.md)。

## 采集结束

检查本次会话是否生成，抽查视频的开头和结尾，确认任务完整、画面无遮挡。将完整会话目录复制到工作电脑，并按[导出与检查](export.md)确认结果。

不要在录制或保存过程中拔出存储介质、断电或移动原始文件。清理设备数据前，先确认已有完整且可用的副本。

## 怎样减少重采

| 容易忽略的情况 | 建议 |
| --- | --- |
| 关键动作离开画面 | 正式开始前用同样姿势完成短测试 |
| 头发或衣物遮挡镜头 | 佩戴后检查各路画面，调整后重新检查 |
| 光线变化造成画面难以辨认 | 在实际任务位置测试，避免强逆光 |
| 只复制了视频文件 | 以完整会话文件夹为单位保存和上传 |

发现问题时，查看[常见问题排查](troubleshooting.md)。
