## Include these details

Copy the template and fill in the information you can confirm:

```text
Product: SynerMind Ego 4
Device serial number (SN):
Hardware / firmware / software versions:
Computer OS and uploader version, if relevant:
Time of issue, including time zone:
Symptom and exact error message:
Steps to reproduce:
Expected / actual result:
Does it happen every time?:
Actions already tried:
Related session name and validation report, if relevant:
```

Start with error screenshots, necessary logs, and validation reports. If sample data is needed, ask support to confirm the scope and designated submission channel rather than sending an entire batch by default. Never share passwords, verification codes, or private keys.

Stop using the device and contact support if it is damaged, unusually hot, or otherwise unsafe.
