# Settings & Updates

This page covers checks before and after settings changes or version updates. Exact controls depend on the shipped software.

## Change settings

Use the recording configuration provided for your project. Keep it consistent across a task batch where possible. If a change is needed, record it and check a short test recording first.

> **To confirm:** User-accessible settings, defaults, valid ranges, and entry points. Availability of resolution, frame rate, exposure, and time settings must be checked individually; this is not a list of confirmed controls.

## Update versions

1. Record the device model, hardware version, and any available software and firmware versions.
2. Finish recording, wait for saving to complete, and back up existing data.
3. Obtain the matching update package and instructions from the official channel specified by your supplier.
4. Meet the update power requirements and follow the instructions for that release.
5. Verify the version after updating, then check a test recording and its data before resuming normal tasks.

> **To confirm:** Official download URL, version lookup, update method, power requirements, failure recovery, and rollback availability. Executable update instructions cannot be provided until these are confirmed.

If an update fails, record the error and version information. See [Contact Support](support.md).
