# Troubleshooting

> **Status: Review draft; content pending verification.** Resolve all “To confirm” items before publishing as user instructions.

[Guide home](index.md) · [简体中文](../zh/troubleshooting.md)

Find the symptom and perform the basic checks below. If the problem persists, preserve original data and error messages, then see [Contact Support](support.md).

| Symptom | First check | Next step |
| --- | --- | --- |
| Device does not power on | Power connection, specified accessories, and visible damage | Follow the supplied instructions; contact support if there is no response |
| Recording will not start | Battery, storage, or device warnings | Record the message and follow verified operating instructions |
| View is blocked or blurry | Lens cleanliness, fitting direction, hair, and clothing | Adjust and run another short test |
| Session cannot be found | Whether recording stopped and saved; correct device and storage location | Preserve existing files; do not format storage to attempt recovery |
| Copy or validation reports missing files | Whether the complete session was copied and source storage is readable | Compare source and destination; do not invent replacement metadata |
| Incorrect date or time | Clock-related warnings in the validation report | Preserve the data, record the issue, and assess its impact before use |
| Collecta reports an unregistered or unassigned device | SN, device status, and collector assignment | Ask an authorized person to register or correct the assignment |
| Task unavailable in Collecta | Whether the task is published and your account has access | Check with the project administrator |
| Upload interrupted | Network, source access, and computer sleep state | Keep files accessible and follow uploader instructions |
| Processing fails or quality checks fail | The specific failure in session details | Follow the report; contact support or repeat recording if source data is faulty |

> **To confirm:** Add official Ego 4 error codes, indicator-based diagnostics, and model-specific recovery procedures. Unverified reset, flashing, and formatting procedures are not provided here.

## Before contacting support

Prepare the device SN, versions, time of failure, reproduction steps, and error screenshots or validation reports. Check logs for account details or sensitive content, and share only what is needed through the designated support channel.
